# Font drop zone

请把希望网站使用的、已获得授权的字体文件放在这里。当前只创建投放目录，等文件和元数据确认后再注册 `@font-face`，不会猜测或替换未知字体。

## 推荐格式

- 首选 `.woff2`，体积更小、网页加载更合适。
- 可以同时提供同一家族的 `.woff` 作为旧浏览器回退。
- 不需要提供 `.ttf`、`.otf` 或压缩包；如果只有这些格式，请先确认是否允许转换为网页字体。

## 请随文件附上

- 字体家族名（family name）。
- 每个文件的 `font-weight`，例如 400、500、600、700。
- `font-style`，例如 `normal` 或 `italic`。
- 是否为 variable font；如果是，请注明 `wght`、`wdth` 等轴及其范围。
- 中文覆盖范围或语言子集；如果有简体中文 subset，请一并说明。
- 授权/许可证来源，以及是否允许用于公开网站。

建议文件名包含家族和字重，例如 `ExampleSans-Regular.woff2`、`ExampleSans-700.woff2`。
